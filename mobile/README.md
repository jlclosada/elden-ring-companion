# Sendero de Gracia · app móvil

App nativa (iOS y Android) del asistente de Elden Ring, hecha con Expo SDK 57 y Expo Router. Comparte los datos y la lógica de la web (`../src`). Instrucciones de uso y arquitectura en el [README principal](../README.md#app-móvil-ios-y-android-expo).

```bash
npm install
npx expo start
```
