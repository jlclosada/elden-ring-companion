# Datos de marcadores — CreateDDy/EldenRing_MapInteractive

Coordenadas en píxeles de los mapas del juego (gracias, jefes, mazmorras, prisiones eternas, mausoleos,
mercaderes, semillas doradas, lágrimas sagradas, fragmentos del Árbol Umbrío y cenizas veneradas).

- Origen: https://github.com/CreateDDy/EldenRing_MapInteractive (release V1.2.5)
